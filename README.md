# Prithvi-WxC MERRA2 Preprocessing

Preprocessing for MERRA-2 data used with Prithvi WxC.

## Structure

- `src/prithviwxc/` – Core package
- `scripts/` – Entry points
- `examples/` – Example usage

## Usage

From project root:

```bash
export MERRA_HOME=/path/to/MERRA2_all
export OUTPUT_DIR=/path/to/output
python scripts/run_single_day.py
```
